# OrthoManager

Gestionale pazienti ortopedici — Material Design 3

- Database online persistente via JSONBin.io
- Auto-sync ogni 30 secondi
- Multiutente (fino a 20 operatori)
- PWA-ready (funziona su mobile e desktop)

## Stack
- HTML/CSS/JS puro — nessuna dipendenza
- JSONBin.io come backend database
- Material Design 3 + Material Icons
